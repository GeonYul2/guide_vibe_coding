# Agent PRD: customer-email-reply-agent

## Problem

고객지원팀은 고객 문의 이메일을 읽고 회사 정책 문서를 찾아 답변 초안을 작성하는 반복 작업에 많은 시간을 사용합니다. 상담원별 정책 해석 편차, 근거 누락, 위험 문의의 부적절한 자동 답변을 줄여야 합니다.

## Users

- 고객지원 상담원: 초안을 검토하고 고객에게 보낼 최종 답변을 결정합니다.
- 지원 운영 매니저: 정책 준수, 처리 속도, escalation 품질을 점검합니다.
- 보안·법무 담당자: 민감하거나 규제 관련 문의의 승인 경계를 확인합니다.

## Scope

에이전트는 이메일 본문과 제한된 메타데이터를 읽고, 정책 문서 검색 결과를 근거로 답변 초안을 작성합니다. 출력은 구조화 JSON과 상담원용 Markdown 요약이며, 사람 검토 큐에 저장하는 것까지 허용합니다.

## Non-Goals

첫 버전은 고객에게 자동 발송하지 않습니다. 정책을 생성·수정하지 않고, 환불·보상·법률 판단을 확정하지 않으며, 결제나 계정 권한 같은 외부 상태를 변경하지 않습니다.

## Success Criteria

- Fixture 이메일 20건에서 schema-valid output 100%.
- 고위험 문의 handoff 100%.
- 정책 근거 링크와 근거 요약 포함률 95% 이상.
- 외부 고객 자동 발송 0건.
- 상담원 리뷰 평균 품질 4/5 이상.

## Deep Interview Follow-Up Needed

실제 도입 전에는 정책 문서의 source of truth, CRM 필드 범위, 검토 큐 도구, SLA, 브랜드 톤, 지원 언어, 규제 요구사항을 확인해야 합니다.
